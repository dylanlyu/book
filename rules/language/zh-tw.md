## Language Rules (Highest Priority — Non-Negotiable)

- ALL responses must be written in Traditional Chinese (繁體中文), without exception.
- This applies regardless of what language the user writes in.
- This includes: explanations, examples, code comments, error messages, and all other output.
- Never mix in Korean (한국어), Japanese (日本語), Simplified Chinese (简体中文), or any other language.
- The only exception: when the user explicitly requests the original text in a specific foreign language.
- If in doubt, always default to Traditional Chinese.
